# 推理时潜变量优化（实验开关）

日期：2026-10-09。默认关闭，不更新任何模型权重，不需要新增训练数据。不改变现有 adapter 的选择；本地对照使用既有 MagicBrush pilot，不能把它误称为一个从未训练过的模型。

## 使用

在原有 `inference.py --method source-conditioned` 命令中增加：

```text
--preservation_optimization latent --preservation_keep_mode off --text_guidance_scale 1
```

仍需显式提供模型、adapter、源图、指令以及绑定该源图的 K/M 权限文件。省略开关或指定 `--preservation_optimization off` 即为原路径。优化不能与 `project` / `source-memory` 或 CFG>1 同时开启；旧 `baseline` 入口也不接受该开关。输出文件及 JSON 不覆盖已有文件。

## 本轮具体优化内容

Boogu 使用 `t=0` 为噪声、`t=1` 为图像。在选定时间步，固定 DiT 当前预测 `v`，形成干净潜变量近似：

```text
anchor = z_before + (1 - t) * stop_gradient(v)
loss = source_keep_proxy(decode(x), decode(source_mode), K)
     + 1.0 * edit_region_MAE(decode(x), stop_gradient(decode(anchor)), union(M))
     + 0.1 * mean((x - anchor)^2)
z_next_corrected = z_next + t_next * (x - anchor)
```

只对当前图片的 `x` 求梯度。DiT、VAE、adapter 权重冻结；Qwen 编码不参与优化。VAE 为 FP32，DiT 仍为原生 BF16/现有 FP8 权重配置。最终输出仍是完整潜变量的 VAE 解码，不进行源 RGB 拼贴。

固定原型参数：时间窗 `[0.60,0.95]`，每 5 个原生采样步检查一次，每次最多 4 次内部更新；归一化梯度提议 RMS 为 `0.03`，相对当前 anchor 的总修正 RMS 不超过 `0.08`。每次最多尝试 4 个减半步长。只有总目标严格下降且 keep 代理损失不增加时才接受。验收检查的是实际 BF16 加法量化后可施加的修正，而非仅检查理想 FP32 提议。无有效 K、时间步不匹配、梯度为零或没有通过验收的提议时，不施加修正。

K/M 使用原始 RGB 分辨率权限；多对象逐属性取最大值，失效参考不能变成 K，未知不能变成 K，同一属性 K/M 冲突报错。不会把“结构要保留”改成“整块像素锁住”。

输出 JSON 中 `inference_optimization` 包含固定参数、每步/每次回退记录、损失、修正幅度及零权重更新声明。

## 解释边界

- 这是停止 DiT 梯度的近似终点优化，不是贯穿 50 步轨迹的精确梯度，不是 FlowEdit。
- keep 使用现有 RGB、色度、亮度差分/Sobel 和高频代理；它们不等于面部身份、毛发几何、文字或物体关系的一致性指标。
- 编辑锚点来自模型自身当前预测，而不是目标图或人工正确答案。因此它可能保留模型原有错误；该项只限制对当前编辑预测的破坏，不保证编辑成功。
- 潜变量修正和 VAE 解码可能影响掩膜外像素。代理损失下降不保证最终图像更好，必须检查采样结束后的图像。
- 权限若只有空间 pixel-K，则只验证空间保护；不能宣称已经提供对象内部的属性选择能力。
- VAE 求梯度增加显存和时间。尚未证明该默认原型的质量或泛化能力，不能直接推广为生产默认。

## 本地受控实验

本节记录本地已经完成的诊断，不是 GitHub 下载包中的可运行实验命令。私有执行器、源图／权限缓存、模型和实验产物均不随源码分发。下载包使用本文开头的正式 CLI 开关，配合你自己的源图、权限和兼容 adapter 运行。

必须使用不存在的新输出目录；重跑时改成新的名字。协议固定 4 张真实照片、6 个案例/种子设置，`off` 与 `latent` 共 12 次生成，Euler50、CFG1、同一既有 pilot adapter。先运行并精确复现全部历史 off 输出，再进行任何优化对照。目标图和评价区域不传入优化器。

这是已知失败案例的机制诊断，不是独立留出泛化评估。对照包括狗换色、狗不编辑、自行车换摩托车（两个种子）、删棒球和飞盘换球。联系图额外展示带明确标签的 10 月 7 日缓存 project 结果，不计为本轮新生成。

## 属性锚定消融（2026-10-09）

增加 `--preservation_edit_anchor attribute` 可选择新的编辑保持表达；默认仍是 `rgb`，整体优化默认仍关闭。该选项必须同时指定 `--preservation_optimization latent`。不是新增训练，也不修改权重。

旧 RGB 锚点将所有 M 合并后逐像素比较，因而对颜色-M 也约束了空间细节。本轮仅替换这个表示：颜色-M 在每个对象原始支持上约束 RGB 通道均值和标准差，损失为 `mean(abs(mu-mu_ref)) + mean(abs(std-std_ref))`。标准差使用中心方差 `sqrt(var + 1e-8)`，保留亮度信息且避免纯色区域的非有限梯度。结构-M 仍用一阶差分和 Sobel（半径 1 腐蚀），纹理-M 用高频代理（半径 2）；glyph/pixel-M 是 RGB 代理，不是 OCR 或物体语义监督。空腐蚀支持不参与损失。同对象内平均活跃属性，再平均活跃对象；结构两个算子合为一个属性项。颜色统计不跨对象混合。只有 pixel-M 或没有 M 时，精确使用原 union-M RGB 规则。

这是将空间约束放宽为统计约束，不是证明属性解耦。锚点仍来自模型自身当前预测，可能已经错误；六个边缘统计量不能保证编辑成功或物体身份，也不能保证空间颜色分布。新旧表示的损失尺度并不完全相同，本轮不据输出调整权重或掩码。K 的代理和验收标准保持原样，最终颜色变化和结构都需要单独检查。

固定对照及产物位于 `outputs/attribute_anchor_20261009/`：复用经过哈希验证的上一轮 6 组 off/RGB 结果，先新增 off/RGB 小狗精确复现门，再新增 6 组 attribute 推理。MagicBrush 样本只有空间 pixel-M，因此它们是数值兼容性对照，不能据此宣称任意对象替换／删除已具备语义属性约束。全程目标图仅用于生成完成后的评价。

该本地对照已完成：8 次新增推理（2 次精确回放、6 次 attribute）及 12 个历史缓存比较。小狗非编辑区 MAE 下降 8.56%，对象内部结构代理误差下降 10.44%，但主要毛发形态与面部细节仍改变。其他五组是逐值相同的兼容性对照，不是五个质量提升案例。源 RGB／边缘代理不等于语义身份评价；新旧锚点尺度也不完全相同。因此默认优化仍关闭，默认锚点仍是 RGB。
